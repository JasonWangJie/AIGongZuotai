# 2026-11-22-149 项目漫剧分镜本、原图绑定与作者确认

## 目的

作者可在同一项目的多个镜头复用角色与场景，修改角色姓名、场景说明和镜头顺序后仍可核对以前确认的原稿。保存与确认分别签发原键收据，客户端在提交结果不明时能只读查证。

## 范围

V21-B1 的 H01 身份与权限、H02 项目修订、H10 分镜创作。数据库保存项目内的分镜文本、图片身份及作者确认。公开工作台、分镜文件交付、浏览器与联合恢复见同批相应台账。

## 接口与数据影响

- 每项目一本。031 增加 `studio_comics`、`studio_comic_versions`、`studio_comic_assets`、`studio_comic_receipts`。第一次保存传预期版本 0，后续保存传当前版本。事务先重核账户、会话及作用域，并锁定稳定项目行，首次创建也按同一规则串行。每次只前进一个版本，最多 128 版；历史分页最多 50 项。修订、原图绑定和收据均不可改删。
- 每版含一个标题和故事、各 1–16 张角色卡和场景卡、1–12 个有序镜头。镜头只可引用本版已有场景与 0–8 个不重复角色；同一角色或场景可在不同镜头反复引用。ID 为 1–48 位 ASCII 字母、数字、下划线或短横线，标题最多 120 字符，故事 4000 字符，卡名 80 字符，描述、动作及台词各 1000 字符；规范化正文最多 256 KiB。后续版本改名、调整故事或镜头顺序时，原版本仍保留全部卡片与关系。
- 单版最多四个图片镜头，单个原图不超过 8 MiB，逐镜累加最多 32 MiB。复用 029 的私有参考原图和已交付生成图鉴权，仅接受同项目当前可见的 PNG／JPEG。保存检查所选修订并冻结 SHA-256 和私有原件身份。读原件时重新核对资产状态、内容摘要、私有回执与现有审核决定；已回收、隔离或原件定位改变时保留旧版文字，单镜读取重新核该镜，全稿导出需要全镜通过。
- 保存与确认分别绑定项目、操作、当前用户、完整请求摘要及稳定键。原键重放先于容量与版本冲突检查；同键改请求会冲突。每版作者只可在该版仍为当前版本、所有已选图当前可见时确认一次。成功确认收据与该版作者有数据库外键关联，后续改稿从未确认的新版本开始。再次读取曾经确认过的版本仍能看到确认状态，当前原图是否可用单独计算。作者确认仅用于交付分镜稿，平台内容审核、生成任务及原权益账务保留各自的状态。

## 风险与限制

本批没有真实邮件邀请、供应端逐镜生成、配音或字幕合成的实测。作者确认后资产仍可能被回收或隔离，使用者需重新读取原图状态。每项目及每操作的行数由版本上限和镜数约束，应用继续单控制写者运行。

## 回滚方式

停止写入，保全 031 数据库、原件／参考私有目录及身份、有关对象版本和已启用的密钥。需要退回 030 时，使用升级前配套备份和对应版本程序在独立位置恢复，核对备份点后的新分镜、作者确认以及其他项目写入。保留 031 副本供对账；删除迁移登记会破坏旧写者栅栏。
