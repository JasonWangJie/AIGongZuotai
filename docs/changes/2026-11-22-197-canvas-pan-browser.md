# 2026-11-22-197 项目自由画布的真实项目、私图和 Chromium 平移验收

## 目的

验证 V17 方案的两档项目图在真实编辑器内的平移帧耗时，同时给出每档图实际绘制内容及项目权限的证据。两个项目分别保存 500 节点与 1,000 连线、2,000 节点与 4,000 连线。

## 范围

覆盖 H01 当前会话、H02 项目修订、H08 浏览器交互和 V17 性能验收。工作台采用实际构建文件、037 PostgreSQL、正常登录、私有磁盘、环回 HTTP 媒体审核及文本生成测试服务。正式每档连续拖动至少 60 秒。短试每档 3.5 秒并在报告中标为 pilot。

## 实际文件

- `internal/studio/canvas_pan_browser_test.go` 从正式入口创建、审核和保存测试资源，核验旧版、新版、访问拒绝、执行次数及两次聊天终态。
- `apps/workbench/scripts/canvas-pan-browser.mjs` 在全新 Chromium 配置目录登录，用 CDP 鼠标拖动并观测加载、渲染、编辑、保存及切换项目。
- `apps/workbench/scripts/canvas-pan-samples.mjs` 与 `scripts/perf/canvas-pan-samples.test.mjs` 计算原始帧间隔的最近秩分位数并归类图形渲染器。Node 专测置于根性能脚本目录。
- `apps/workbench/scripts/local-browser.mjs` 增加显式启用 GPU 的测试选项和有限的浏览器渲染信息读取，原调用默认参数保持原行为。

## 接口与数据影响

测试生成两个普通账号、同一所有者的两个项目和两个相异的 640 × 360 PNG。图片必须通过现有媒体审核并取得有内容身份的私有缩略图，浏览器实际解码且比对服务器登记原件所对应缩略图的字节摘要。两笔正常受理的聊天保持环回流连接，画布与数据库均须显示 RUNNING，测量结束才关闭流并核验 COMPLETED。其他账号对两份画布及缩略图的四个请求均须遭拒绝。

画布第 1 版经真实 PUT 保存。编辑时变更首个节点的坐标与标题，检查 Canvas 2D 实际绘制的相邻线段端点、分组折叠与展开。再保存第 2 版，切走并重开项目，逐项对照两版，校验旧版、原连线、其他节点及项目私图。浏览器监测生成 POST，Go 也核对环回上游实际次数。试具只写隔离测试库、临时私有目录和一个明确指定的新报告路径。

## 风险与限制

该实验的 rAF 数值描述热画布的浏览器动画帧间隔，不能换算成物理显示器的呈现时间或输入端到端延迟。硬件选项允许浏览器尝试本机 GPU；只有合成启用且实际渲染器可识别时才标注 hardware，SwiftShader 等标为 software，缺少识别证据保留 unknown。本机 Chromium、模拟带宽和环回上下游的结果不能替代指定四核、16 GB、集显实体参考设备或手机上的重新测量。完整真实 PostgreSQL/Chromium 数值以集成人保存的实测报告为准。

## 回滚方式

本项只增加验收试具及浏览器辅助选项。已有浏览器检查保持默认软件模式。撤回本项时移除上述专项及辅助可选字段；产品数据格式与生产服务入口由 195/196 管理。专项仅在新建的隔离测试 schema 和私有临时目录写入。

## 037 画布实际平移验收

在本机 Intel 集显、Chromium 157、1920×1080 下，两档各实际拖动平移 60 秒，期间私有缩略图已解码、已受理 Run 持续活动。500 节点/1,000 边的 3,599 个帧间隔 P95 为 16.8 毫秒，最多 25 个详细节点；2,000 节点/4,000 边的 3,601 个间隔 P95 为 16.8 毫秒，最多 100 个详细节点。两个项目实际保存并重开 4 个修订，编辑与平移新增生成 POST 为零。 两组最大间隔分别为 67.2 和 33.3 毫秒。137.271 秒专项通过。报告使用前台浏览器 rAF 间隔，系统可用内存约 31.5 GiB；当次网络按 20 Mbps / 80 ms 配置，实际往返与吞吐校准单列。桌面与 390 CSS 像素截图已人工核对。 [全部帧间隔与逐秒样本](../wiki/assets/performance-canvas-037.json)。

## 037 画布修正后的再次实测

完成画布来源补读与存储失败修正后，在同一宿主、启用硬件加速的最终工作台重新跑足两组各 60 秒。普通/压力档分别采到 3599 和 3602 个有效间隔，P95 均为 16.8 ms，最多展示 25/100 个详细节点。私有图已解码、原 Run 活动且新增生成调用为零；go test 用时 132.443 秒。 [第二次完整帧样本](../wiki/assets/performance-canvas-037-recheck.json)。
