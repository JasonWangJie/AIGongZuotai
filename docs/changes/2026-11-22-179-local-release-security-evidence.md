# 179 · 发布安全与供应升级的本地证据归集

## 目的

为 V22 原有的安全测试及供应升级回归验收提供一个可定位的本地证据入口，让使用者能从结论找到原运行日志、测试名称、源断言和所属数据库格式。

## 范围

覆盖 032 累计与 033、034 专项中的登录、密码、作用域、角色和撤权、私有文件、个人资料、订单与权益、联备恢复以及供应适配兼容。034 的制品与锁定依赖比对单列。035 完整运行留待集成人实测补记。

## 实际文件

- `docs/wiki/release-security-evidence.md` 按控制和升级路径归集现有证据。
- `docs/changes/2026-11-22-179-local-release-security-evidence.md` 记录本次归集的范围与依据。

## 接口与数据影响

仅整理已存在的验证事实。文档记录固定接口路径、名称、状态码及耗时，不含账号、真实交易身份、环境地址、凭据、私有资源 ID 或业务正文。运行程序、数据库格式、权限及发布流程均沿用既有实现。

## 验证结果

逐项匹配本机累计及专项目录的通过记录，并核对源测试对访问边界、权限和恢复结果的断言。032 工作台累计实测 1639.820 秒；033 订单与个人资料专项合计 62.099 秒；034 工单及升级专项合计 48.800 秒，034 只读对账数据库专项 3.15 秒。各组测试名称、进一步的源文件及实际时间见[本地证据清单](../wiki/release-security-evidence.md)。

只读校验将清单中 25 个具名用例的耗时与原日志 PASS 行逐项匹配，并在链接的 Go 测试源码中确认同名函数。两份文档共 28 处相对链接均有目标，另检查了地址、邮箱和资源身份格式。原测试和数据库均未重新运行。035 完整累计运行与外部供应商升级前后版本验收分别登记。

## 风险与限制

本地环回适配、数据库升级和锁定依赖核对可用于发现工作台自身的兼容性变化。外部生产网关、商户、SMTP、实际部署与负责签收的人员均需相应环境的真实验收。

## 回滚方式

若引用发生变化，按原日志和源断言校正本条与 Wiki 的引用。纯文档归集不涉及运行数据回滚。

## 文档同步

本记录归属 V22 的原验收条目。README、Wiki 导航、台账索引及任务源由集成人按最终运行结果同步。

## 034 累计运行与剪辑选择问题

固定 034 累计运行 studio 1702.178 秒，视频导出包通过（2.465 秒）。611 个顶层用例通过，1 个失败，0 个跳过。唯一失败是视频剪辑 Chromium 用例（14.72 秒）：核对首次保存的原回执后，页面已显示固定版本，项目选择框在目录响应前读到空值。订单、资料、客服和只读对账均实际通过。该轮完整结果为失败，后续制品保留原浏览器断言复验。

固定 035 完整回归通过，629 个顶层用例，零失败、零跳过。studio 包 1670.146s，视频导出包 2.669s。实际启用 PostgreSQL、版本化本机对象存储、真实 Chromium、FFmpeg、十万调度积压、二十万旧任务迁移和编译出的只读订单核对命令。该制品的 553 项工作台测试、157 模块生产构建、Go vet 和六套冒烟均通过。
