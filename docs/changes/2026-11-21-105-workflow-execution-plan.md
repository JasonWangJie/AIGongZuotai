# 105 · 可执行工作流与模板契约

## 目的

V19 的 V03/V06/V09 依赖已具备。把总体设计中的不可变 DAG 运行、人工选片和资产溯源落实为下一条可实际操作、可验证的工作台链路。

## 范围

设计覆盖 H02/H03/H10/H08。第一条用户链路从模板或草稿到文本、图片产物及跨会话确认，完整模板继续消费选定图片并交付视频。节点重跑、取消、持久恢复及权益独立核验。

## 实际文件

- `docs/planning/v19-contract.md` 对齐任务源、原设计与现有前后端入口，给出三个子批的边界、验收场景和复跑路径。
- `docs/changes/2026-11-21-105-workflow-execution-plan.md` 记录本次设计与证据范围。

## 接口与数据影响

本轮交付文档。003 的项目文字草稿、现有 Run/Task 与资产接口沿用原契约。后续拟增加流程定义版本、运行快照、节点尝试和人工选择，以稳定键关联原有子执行。图像进入视频请求须登记并验证实际视频输入类型和适配协议。

## 验证结果

已对照总体设计第 12、15 节和 `tasks.json` 的 V19 三项验收，逐项核对草稿数据库及 API、画布与灵感模板、生成受理、模型能力和资产登记路径。文档列出的运行、收费防重、真实输入与浏览器用例为实施验收条件。V19 本轮没有可运行实现，尚无其功能测试、真实供应商或浏览器验收结果。

## 风险与限制

未持久关联节点尝试和子资源会让流程重试造成重复收费；运行中修改草稿会改变尚未派发的节点输入。原媒体生成接口尚不能消费选中图片作为视频输入。上述情况分别在版本冻结、故障恢复与实际输入字节验收中检查。

## 回滚方式

本轮没有运行时或数据库迁移。方案调整通过后续台账更新契约和导航，并保留已记录的验收边界。
