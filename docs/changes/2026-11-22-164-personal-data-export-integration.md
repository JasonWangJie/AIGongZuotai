# 164 · 普通及受限账户的本人资料下载

## 目的

验证账户本人可在浏览器取得资料，操作受限时仍可取得自己的申诉记录，并核对多页下载与数据库中的原记录。

## 范围

V22-A 涉及 H01 登录与凭据、H06 账户事件和 H08 工作台。覆盖已有三个本人资料分区、两个独立账户和跨页读取。

## 实际文件

- `internal/studio/http.go` 注册认证域的下载入口。服务端分页、凭据重核和专项测试见 [162](2026-11-22-162-account-data-export.md)。
- `internal/studio/personal_data_browser_test.go` 创建普通用户和独立的受限申诉人，使用实际浏览器及下载目录核对原始资料。工作台和浏览器程序见 [163](2026-11-22-163-account-data-export-workbench.md)。
- `docs/api/openapi.yaml`、`docs/wiki/account-data-export.md`、README、Wiki、规划、协作规则、台账索引和生成 TODO 同步接口和验证状态。

## 接口与数据影响

`POST /api/v1/auth/data-export` 由当前会话定位用户，单次请求包含分区、当前密码和可选原游标。成功响应为私有 JSON 附件，返回长度和原始字节 SHA-256。数据库沿用已有用户、会话、安全事件和账户申诉表，无新增迁移。

## 验证结果

集成人对冻结的 033 运行真实账户及 PostgreSQL 专项。会话撤销与账户分区 4.54 秒，申诉隔离与强转义字节分页 4.37 秒，双账户 Chromium 下载 10.11 秒。四份文件分别包含一份本人资料、100 加 12 条安全事件及一份受限账户本人的申诉；数据库逐条核对顺序、范围和原始申诉正文通过。

- `go test -count=1 ./internal/studio -run '^TestAccountExport'` 通过，0.164 秒，同时编译了真实浏览器/PG 联验程序。
- 工作台 504 项测试、152 模块构建和独立本机 HTTP 浏览器下载见 163。
- 真实 PostgreSQL 专项、普通与受限账户真实浏览器下载及累计回归待集成人串行执行。联验通过后补记耗时。

## 风险与限制

测试通过应用例程预置 110 条安全事件以覆盖分页，另由真实登录产生登录记录。核对用户可下载的所有页及数据库原编号与顺序。下载使用者负责自己设备中的文件。整站隐私政策、项目数据可携性与公众发布分别跟踪。

## 回滚方式

在同一数据库格式恢复上一服务端和工作台制品，账户和安全事件继续保留。此功能未新增持久授权或修改个人资料。
