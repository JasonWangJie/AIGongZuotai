## 风险与限制

已编译程序仍包含构建时 SQL；本次不是热加载或运行期从磁盘切换脚本。现有 `studio_schema_versions` 只保存版本/时间，没有脚本摘要列；不宣称新增了已应用内容校验或向下迁移。PG 首轮环境失败及恢复后的四项成功均保留。复验连接独立55433测试实例，通过忽略的 `validation-postgres.env` 注入；没有覆盖原 `postgres.env`、备份或开发库，没有将连接串写入台账。

## 回滚方式
