# 243　039 本机累计回归

## 目的

核对格式 039 的完整程序、前端和配套对账工具能否覆盖既有功能，以及新加入的原视频、SSE 和媒体查询路径。

## 范围

本机 Windows、PostgreSQL 16.14、隔离环回服务和 Chromium。关联 V17、V20；既有模块的实库、浏览器与联备用例按原入口运行。

## 实际文件

本记录、根 README、Wiki 导航、台账索引、推进记录、任务源及两份生成 TODO。私有数据库连接、对象服务参数、临时工作目录和完整日志保存在本机。

## 接口与数据影响

本项只汇总测试证据。实库用例操作独立测试数据库；原视频的对象存储档使用本机版本化对象服务。服务和离线 CLI 从同一工作区构建。

## 验证结果

- 初次无数据库检查在旧版一万订阅测试同时运行时，有一个操作系统套接字归属观测用例超时。两次独立重跑均通过。修复工作室素材重核后从当前工作区再次完整执行 `npm run check`，退出码 0。Go vet、Go 全包、任务检查、57 个前端测试文件共 609 项、183 模块的生产构建及文档检查均通过。
- `npm run test:db` 使用本机受限数据库、FFmpeg/FFprobe 9.1、真实 Chromium、私有版本化 S3，以及 039 同源服务和对账 CLI。完整运行退出码 0，754 个顶层测试通过，23 个显式条件或辅助进程用例跳过，零失败。`internal/studio` 耗时 1948.940 秒。原视频 Chromium 常规场景 15.79 秒、无响应头 12.55 秒、版本化对象联备 22.96 秒、038 旧库升级 2.03 秒。[去敏报告和跳过项](../wiki/assets/format-039-regression.json)两个新增浏览器专项、原视频联备、六个查询池专项及容量压测另有独立记录。
- 同一 SHA-256 服务运行 `npm run smoke`、`smoke:runtime`、`smoke:catalog`、`smoke:references`、`smoke:library`、`smoke:conversations`，六套环回冒烟退出码均为 0。
- 对 038 与 039 的生产前端制品执行工作台 `pr-bundle-diff.mjs`，依赖锁相同。已识别的去重启动 gzip 从 169,569 字节增至 174,456 字节，仍低于 307,200 字节预算；其余独立分包合计 531,882 字节。该项为本地实物大小比较。
- 本轮服务 SHA-256 为 `16c44bf284c015ef6fbf9db75d824494ade794aab227a95e001a199e4839c843`，对账 CLI 为 `3119fd59aa586400f9eb5e09c754f0886665b595d7462b0a44bd58e376382c58`。

## 风险与限制

长回复累计使用 quick 档。30 分钟长回复、一万 SSE、264 个模型连接与 24 小时容量各有独立条件。真实供应商、收件邮箱、商户和异地恢复没有纳入本机结果。

## 回滚方式

本记录不变更服务。若需旧格式，停写留存当前数据库、私有目录、对应对象版本及启用的密钥，在独立位置使用同格式联备和旧制品恢复。
