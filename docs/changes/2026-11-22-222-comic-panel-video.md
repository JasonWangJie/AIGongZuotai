# 2026-11-22-222 已确认分镜的单镜文生视频

## 目的

创作者可在固定分镜版选一镜，核对实际送往模型的提示词和规格，显式接受一个视频任务。重新制作保留之前的任务、报价和成品，受理回执遗失可以用原键查询。

## 范围

V20-B 的 H02 项目与创作数据、H03 模型与执行、H04 资产与交付及 H10 专项创作。复用 031 分镜作者确认、现有普通文生视频、审核、收费和任务交付。将已批准成品写入剪辑稿与浏览器交互由同批其他子项登记。

## 实际文件

- `db/migrations/038_comic_panel_videos.sql` 新增已受理任务与固定镜头的不可变关系，增加未消费原报价查询索引。
- `internal/studio/comic_panel_video.go`、`comic_panel_video_store.go`、`comic_panel_video_http.go` 处理固定分镜文本、授权、尝试序号、报价、受理、原键回执和分页。
- `internal/studio/comic_http.go` 注册四个项目范围接口。`app.go`、`billing_http.go`、`persistence.go` 对接普通任务、报价与单事务受理。`workflow_rerun.go` 提取原有媒体任务再做的安全状态检查供两处复用。
- `internal/studio/comic_panel_video_test.go` 覆盖固定文本、账务与来源、重复和重做、丢失 COMMIT 确认及 037 数据升级。

## 接口与数据影响

路径前缀为 `/api/v1/projects/{project}/comic/versions/{version}/panels/{panel}/videos`。每次新操作由创作者选择一个新 `Idempotency-Key`。`POST /quote` 使用该键及当前视频模型 ID、公开版本、单个视频的规格，返回有效参数、完整文本及下一尝试编号。提示词取自原分镜版的作品名称、故事、该镜标题、选定场景、按镜头原顺序选择的角色、动作及对白，最大 16,000 UTF-8 字节，同时遵守所选模型的更小限制。接口拒绝客户端自填提示词、私有文件、URL 或供应商字段。所选分镜可以有参考图；这个文生视频操作只发送上述文本和视频规格。

启用 CREDIT 时复用普通报价、当前价格和受理冻结。报价摘要包含当前用户、工作区、项目、固定分镜版本、镜头、操作键、尝试和完整普通媒体输入。同一操作再次预览可以读取仍有效、未消费且价格版本相同的原报价。权益关闭时预览给出实际文本及规格，返回 `billing_enabled=false`，不会造报价或分录。

`POST` 前缀本身使用相同键，携带预览的 `expected_attempt` 和启用权益时的 `quote_id`。首次受理返 201，同一输入的原键回放返 200。当前会话、固定作者确认、原提示词、原尝试和报价随受理重核；task、冻结、审核记录、幂等、审计、Outbox 和来源关系同事务提交。受理成功后，重复请求的判断优先于现目录和重做条件。`GET /receipt` 只能查询当前操作者在该项目、版本及镜头的原键；`GET` 前缀本身按尝试倒序读取，支持 `before_attempt` 和 `limit`（默认 16，范围 1—32）。每个固定版的一个镜头最多 32 次成功受理。等待处理、受理不明、待核实和无法确认上游已停的取消均不允许开始新尝试，已确认交付继续沿原 Task 和资产范围读取。

## 风险与限制

该链使用普通文生视频。源视频编辑、供应商延长、私图首帧、画面语义和真实计费渠道仍按已有专项与外部条件验收。作者确认是创作记录；实际输入、输出的内容审核及发布继续服从原通道。提示词超限会在报价或受理前明确拒绝，请作者精简后另存并确认。每镜尝试上限计入此前完成或取消的记录，已受理收据不因额度耗尽而失效。

## 回滚方式

停写并联合保存 038 数据库、私有目录、对象版本和已启用的相关密钥。若必须恢复 037，使用升级前整套备份与对应制品；另保留升级后的数据供核对新增的生成任务和冻结，避免重发。保持旧迁移登记与来源关系。
