# 144 · 冻结原片裁切、拼接与声音导出

## 目的

为 V20-A1 提供可独立复验的成片执行器。创作者选择的镜头顺序、毫秒段落和声音经真实解码、裁切及拼接进入新 MP4。

## 范围

V20 的 H03、H04、H10。此项覆盖 Windows 本机编解码、资源限制、取消和原件内容校验。项目版本、用户鉴权、素材登记和 HTTP 交付由后续接入验证。

## 实际文件

- `internal/videoexport/export.go` 实现有界受理、私有快照、输出与清理。
- `internal/videoexport/codec.go` 核验原片、组装固定编解码参数和复核成片。
- `internal/videoexport/process_windows.go` 以挂起状态创建编解码子进程，在内存和后代进程上限生效后恢复执行。`process_other.go` 在未适配平台返回不可用。
- `internal/videoexport/export_test.go` 独立生成合成原片，逐帧解码并检验音轨和取消。

## 接口与数据影响

`New(Config{FFmpegPath,FFprobePath,TempDir})` 接受受信的绝对本地路径。`Export(ctx, []Clip, dst)` 接收已鉴权的打开文件、冻结字节数和 SHA-256、起止毫秒，以及调用者持有的空私有常规文件。逐个复制并核对全部摘要，再运行媒体工具。成功返回成片字节数、SHA-256、实际量化时长及画布尺寸。

同时最多一份导出，每份最多 8 镜、30 秒、原片最多 64 MiB、输入合计 192 MiB、成片最多 32 MiB。允许 MP4 中的一路 H.264 及可选的一路 AAC，原片至多 300 秒、60 fps、2073600 像素。单路 768 MiB Windows Job 在子进程运行前生效，单线程编解码，90 秒执行期限，固定本地文件协议、禁止外部轨道。输入文件名、外部地址与客户端滤镜均无对应参数入口。

成片 1280×720、24 fps、H.264、48 kHz 双声道 AAC。按累计时间取最近整帧，每镜至少占一帧；缺声轨补等长静音。视频重新解码，允许从 GOP 中间选择画面。ffprobe 复核最终视频帧数、大小、时长和音轨，完整输出通过核验后写入目标文件。

## 验证结果

在 PowerShell 设置 `$env:VIDEOEXPORT_CODEC_DIR=(Resolve-Path .runtime/v20-codec-9.1).Path` 后执行 `go test -count=1 -v ./internal/videoexport`，四项通过，4.673 秒。FFmpeg/ffprobe 9.1 使用本机合成源：同一 GOP 分别裁出蓝色 880 Hz、红色 440 Hz，再接无音轨绿色。成片逐帧核对 27 帧和 54000 个解码采样点，三个镜头各 9 帧，1125 毫秒。另验证同大小内容篡改、文件和时长限额、文本伪装、原片越界、活编码期间并发拒绝及取消后实际退出、临时目录释放与再次成功导出。未启动数据库或外部供方。

## 风险与限制

本轮实测为 Windows 本机合成素材，其他操作系统、外部供应商生成视频与不同编解码器需另行适配。帧率归一会量化毫秒边界。调用者须提供专属私有临时目录、可信工具包，并在返回成功后发布目标文件。进程强杀可能留下本次私有临时文件。

## 回滚方式

关闭调用入口、等待当前导出退出，撤回新增执行器即可。原登记素材、权益与生成任务没有数据库变更。
