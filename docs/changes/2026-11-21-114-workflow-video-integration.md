# 114 · 已选原件到私有视频的联合验收

## 目的

验证明确选定的原图进入真正的视频 HTTP 请求，视频交付记录可以追溯到原工作流和原资产。

## 范围

V19-B，H02、H03、H08、H10。包含 024 格式、四步工作流、带真实 PNG/MP4 的本机网关、原键与私有访问。真实渠道实测由具备账户和开通模型的环境另行执行。

## 实际文件

- `internal/studio/workflow_video_integration_test.go` 使用真实数据库和 HTTP 适配器，解析 multipart、比较两张选定原件，检查联备后的身份、回放、跨项目拒绝和成品读取。浏览器开关为 `WORKFLOW_VIDEO_BROWSER_TEST=1`。
- `internal/studio/workflow_integration_test.go` 从真实 023 表升级，保留三步模板、决定、意图及收据。`storage_maintenance.go`、`storage_maintenance_delivery_test.go`、`ledger_admin.go`、`operations_admin.go` 更新维护精确版本。
- `docs/api/openapi.yaml`、[决策 0024](../wiki/decisions/0024-video-first-frame.md)、README、Wiki、契约、任务源和生成清单同步。

## 接口与数据影响

四步模板使用已有的项目流程和节点接口，选图后的运行详情含 VIDEO_READY 状态。输入读取绑定工作流和已选图片，权益报价由本步骤单独取得。完成后返回原子任务及项目内可读的视频资产。024 增量只调整流程约束和视频数据，保留 023 文件。

## 验证结果

- 2026-11-21 匿名 GET 原网关文档资源，独立核对 36,004 字节及完整 SHA-256，包含 `input_reference` 和原视频生成路径。实际协议未提交任何收费请求。[协议证据](../../internal/studio/testdata/media/video-first-frame-source.json)
- OpenAPI 本地解析包含 81 个路径，460 项引用均指向存在的组件。
- 024 独立格式构建确认后，真实 PG 串行通过：023→024 保留原选择及收据 1.72 秒，精确维护栅栏 3.40 秒，错报价/原票据不重收 8.97 秒，受理时复核资产 1.06 秒。两个流程选择不同原件、一次停机联备恢复后发起视频，HTTP 供应端逐字节比对 PNG，成品 MP4 的私有读取与跨工作区拒绝通过，21.42 秒。
- Chromium 真实 PG 四步模板、切换授权会话、独立视频授权、私有视频解码和窄屏播放器 16.90 秒通过。该批工作台全测 33 文件 336 项。独立冻结 024 源码与构建后，全量 PostgreSQL studio 包 916.294 秒通过，含本机版本化 S3、真实联备、20 万条恢复、积压预选、混合负载和两种模板的真实浏览器。

## 风险与限制

受控网关可验证文件、幂等与授权；实际渠道支持度、生成质量、计费和生产容量仍需对应环境。服务重启时需要原密钥、私有原件及其冻结提交正文。移动端浏览器的视频解码结果取决于支持的媒体格式。

## 回滚方式

停止写入，保留当前完整联备，再恢复升级前的 023 数据库、配套私有目录、原密钥及对象版本，由对应程序核对既有工作流。保留审计、已计费的子任务和原渠道身份。
