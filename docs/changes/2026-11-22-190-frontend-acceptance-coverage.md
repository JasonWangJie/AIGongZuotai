V17 的 H07 性能、H08 工作台体验和 H03 执行链路。依据总体方案第 14 章核对消息、画布、设备和网络条件。公开版本、真实调用及外部验收仍由各自批次管理。

## 接口与数据影响

仅补全任务与证据范围。本条不扩大持久节点写入限额，也不为旧模板创建新的图数据。

## 验证结果

核对原方案第 14 章规定的两套固定图集、可见节点、帧时间、消息规模与输入响应，以及后端 `conversation.go`、010 迁移、`drafts.go` 及 `workflow.go` 的实际契约。035 单分支上限 128、文字草稿 40 节点，无法用它们验证一万节点的同一分支或数千节点的自由图。集成人执行 `npm run todo:sync` 与 `npm run check:changes`，当次生成结果和文档链接通过，核对 319 份文档、190 份台账。

## 风险与限制

30 分钟单会话与一万条单分支历史各自需要实际证据。多会话合计一万条、静态绘图、桌面模拟窄屏或估算压缩体积只能用于相应范围。发布门槛还包括真实移动设备和参考环境，保留设备、浏览器、缓存与网络口径。

## 回滚方式
