# 152 · 角色与场景复用、固定分镜本和可编辑交付

## 目的

创作者编辑角色、场景和逐镜内容，保存稿件并确认一个具体版本。下载后仍可在办公软件中更改标题与图文，复核同一人物在不同镜头中的动作和对白。

## 范围

V21-B1 使用现有 V08 私图、账户会话和 V21-C 的 PPTX 编写能力。H01、H02、H04、H08、H10 涉及项目权限、版本存储、视图、导出与验收。团队成员、模型生成与音视频合成继续独立验收。

## 实际文件

031 的存储、私有图文 HTTP 和前端工作台分别见 [149](2026-11-22-149-comic-store.md)、[150](2026-11-22-150-comic-private-export.md)、[151](2026-11-22-151-comic-workbench.md)。集成文件包括：

- `internal/studio/http.go` 接入八项项目操作，`internal/studio/comic_integration_test.go` 验证真实账户、浏览器下载、固定稿与私图的配套恢复。
- `internal/studio/storage_maintenance.go`、`operations_admin.go`、`ledger_admin.go`、`storage_maintenance_delivery_test.go` 将维护栅栏升至 031，并检验旧格式、缺号与未来格式。
- `scripts/verify-presentation.py` 独立打开浏览器实际下载件，校验可编辑文本、演讲者备注、图像字节和旧版一致性。长镜头样本另验各页正文拼接与仅首页放图。
- `docs/api/openapi.yaml`、`docs/wiki/decisions/0031-project-comics.md` 和 `docs/wiki/database-migrations.md` 说明接口、用户操作和数据演进。

## 接口与数据影响

登录后读写当前项目的分镜本及历史版本。保存和作者确认分别签发原键收据；图文导出仅针对获作者确认的固定版本。素材的当前权限与平台审核决定在下载前重核。单纯保存、确认与导出均不产生新模型任务或权益冻结。

## 风险与限制

已保存数据在 PostgreSQL 中持久化；未保存的当前编辑输入仍在本页。关闭页面前应先保存或读回相应操作的原收据。该子批提供人工作者确认的分镜稿；外部配音、真实逐镜生成与视频供应商效果另验。

## 回滚方式

停写并联备数据库、私有文件、对象版本与已启用密钥。恢复升级前的一致备份并启动配套 030 程序，在核对恢复点后的分镜及其他写入后恢复业务。已下载的 PPTX 可独立保留。
