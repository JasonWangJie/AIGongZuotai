# 225　已确认镜头生成与剪辑替换集成

## 目的

V20-B 让作者对已确认分镜的一镜核对模型提示和报价，生成一份真正的媒体任务，再选择是否用其已交付的私有 MP4 替换已有剪辑稿中的一镜。

## 范围

H02、H03、H04、H08、H10。从分镜 031 的固定版本进入，复用普通文生视频、额度、审核、资产和 030 版本剪辑。真实模型的原视频编辑和延长另需商定实际输入协议、模型能力、测试素材及授权环境。

## 实际文件

- `internal/studio/storage_maintenance.go` 与 `AGENTS.md` 更新 038 精确维护和版本边界。
- `docs/api/openapi.yaml` 增加分镜报价、显式生成、历史、原键回执及单镜替换五项操作。
- `apps/workbench/scripts/panel-video-browser.mjs`、`internal/studio/panel_video_browser_restore_test.go` 和 `scripts/verify-video-edit.py` 覆盖真实浏览器交互、两份受保护的下载、原库联备与独立解码。
- 根 README、Wiki 导航、数据库迁移说明、030/031/038 决策、台账索引、推进记录和生成的两份 TODO 与任务源同步。生成受理、剪辑存储和工作台文件分别见 [222](2026-11-22-222-comic-panel-video.md)、[223](2026-11-22-223-panel-video-timeline-replacement.md) 和 [224](2026-11-22-224-panel-video-workbench.md)。

## 接口与数据影响

客户端提交模型、完整规格、原键和预期尝试编号。服务端从确认的原版取角色、场景与动作，冻结实际发送的提示及任务关联。生成或剪辑回执未知时按原键读取。替换须指定原剪辑版本和目标 clip，成功后产生新修订。原分镜版、旧剪辑稿与其他镜头可以独立回读。

## 验证结果

本批已开始实施。集成人将用已登录的 Chromium 和隔离 PostgreSQL 验证报价、显式受理、断线查回、选定镜头替换及导出，并检查新旧成片的真实画面、音轨和持续时间。当前没有本批的真实供应商结果。

## 风险与限制

仅对完整受理和已登记的可用产物执行替换。审核隔离、回收、权限变化、旧修订、报价不符及未能确认提交均按原业务门禁处理。样例源片只供本地检查剪辑结果。

## 回滚方式

停写后联备数据库、两个私有目录及 owner、相关对象版本和已启用密钥。在新目录和新库恢复配对的旧格式制品，保留升级窗口的原收据与新原件供核对。禁止删除迁移或已受理媒体任务来回退。

## 集成副本实测

038 稀疏合并后运行 7 项非 PG 专项，包耗时 4.392 秒，其中实际双版独立解码 3.88 秒。新版解码脚本另对既有两份真实 Chromium 下载复验，分别为 67 帧 / 2792 ms、58 帧 / 2417 ms。此次记录与新分镜联动的 PostgreSQL、浏览器及联备验收分别取证。
