# 229 · 窄屏单镜视频表单的标签对比度

## 目的

V20-B、H08。225 桌面实际浏览器截图中，浅色面板上的「目标剪辑稿」「目标镜头」和入出点标签较难辨认。390 像素宽的工作台也使用了同一种颜色。

## 范围

调整「漫剧分镜」下方的「单镜视频」面板。在该面板内为小字、表单标签、分组图例选择深灰绿色，沿用已有的纸张色和控件背景。

## 实际文件

- `apps/workbench/src/panelVideos.css` 在面板上设置局部 `--muted` 颜色。
- `docs/wiki/assets/panel-video-mobile-038.png` 保存 390 × 844 视口的修正后表单截图。图中项目、镜头和媒体条目由本机 HTTP 夹具提供。

## 接口与数据影响

此处只调整工作台样式。视频受理和剪辑替换仍分别使用各自的原键及回执接口。

## 验证结果

- 在隔离副本运行 `npm run build`，TypeScript 通过，Vite 转换 179 个模块，构建耗时 4.69 秒。
- Windows Chrome 157.0.8103.79 在 390 × 844 CSS 像素视口加载构建后的完整工作台。使用常规标题和 112 个连续拉丁字母的合法镜头标题分别重复流程。根据浏览器实际计算的文字与背景颜色，在面板及内部浅色表单上的对比度由 1.76∶1、1.89∶1 提高到 6.38∶1、6.87∶1。两个标题用例的初始、报价、裁切和收据四个状态均无横向溢出，页面及视口同宽 390，面板可用宽和滚动宽均为 311。
- 通过触摸导航打开分镜、预览固定提示词及 0.2 CREDIT 报价，使用 Tab、Enter、方向键和文字输入选择素材、剪辑稿与第二镜，设置 500–1750 毫秒。生成和替换分别在收到响应头后截断响应正文。界面均保留原键，分别发出一次只读核对并显示新剪辑版 v2；每次完整流程在夹具侧各观察到一次报价、一次生成、一次替换和两次对应的原键读取。[窄屏剪辑表单](../wiki/assets/panel-video-mobile-038.png)
- 另在响应头送达前直接断开 TCP，单次浏览器操作曾让夹具观察到同键生成五次、同键替换两次。传输重试仍须由服务端原键机制保护。此轮只验证浏览器行为；真实 PostgreSQL、权益与恢复的结果见 [225 集成记录](2026-11-22-225-panel-video-integration.md)。

## 风险与限制

测试使用桌面 Chromium 的触摸仿真、键盘和本机合成 HTTP 应答，覆盖单镜表单布局、可达性及请求身份。移动真机、真实模型及已交付媒体的业务验收另行记录。

## 回滚方式

撤销面板内的 `--muted` 设置后重新构建工作台。
