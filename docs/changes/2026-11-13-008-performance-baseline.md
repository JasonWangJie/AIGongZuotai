# 008 · 可复现的本地性能基线

## 目的

为后续高性能建设建立可运行、可重复的测量入口，区分实测结果与方案中的目标容量。

## 范围

隔离本地 demo 服务的 HTTP 并发、任务受理和取消、LLM 首增量与完整流基线。无需真实 AI，也不访问正在运行的工作台。

## 实际文件

`scripts/load.mjs`、根 `package.json`、`docs/wiki/performance.md`、`docs/wiki/assets/performance-local-2026-11-13.json`、本台账及 README/Wiki/台账导航。

## 接口与数据影响

新增 `npm run perf:local`。随机端口新建进程，强制 demo、memory 和关闭认证；报告保存在忽略的 `.runtime/performance-local.json`，进程退出后该批任务清空。不提供远程目标选项，不允许把脚本误指向生产 API。

## 验证结果

2026-11-13 14:14（UTC+8），`npm run perf:local` 通过，所有响应与SSE断言成立。Windows 10.0.26100、AMD Ryzen 5 3500X/6逻辑核、约16GiB内存，Node22.18.0、Go1.26.11；同时保留开发工作台和PostgreSQL进程，测试阶段未主动运行其他压测。

| 场景 | 样本/并发 | P50 | P95 | P99 | 吞吐 |
| --- | --- | --- | --- | --- | --- |
| bootstrap HTTP | 1000/32 | 13.32ms | 22.97ms | 32.42ms | 2167.93请求/秒 |
| 创建任务并取消 | 100组/8 | 8.67ms | 12.55ms | 12.69ms | 830.23组/秒（每组两个请求） |
| 完整demo流 | 12/4 | 1706.24ms | 1708.25ms | 1708.25ms | 2.34运行/秒 |
| 创建至首delta | 12/4 | 55.82ms | 56.87ms | 56.87ms | 包含平台受理和演示节奏 |

完整[JSON证据](../wiki/assets/performance-local-2026-11-13.json)保存应用版本、Go版本、二进制SHA256、机器信息与全部统计。修正脚本以纳入构建指纹后重跑；表中仅使用最终这次结果，不以多次运行的最佳值拼接。先前试跑不作为最终容量结论。

## 风险与限制

这是同机、回环 HTTP/1.1、无认证内存 demo 的回归基线，客户端调度也计入延迟。没有测量 PostgreSQL、网关、TLS、多实例、CPU/RSS/FD 或一万活跃流，不能用于宣称生产 SLO 达标。LLM 演示增量人为限速。

## 回滚方式

停止基线命令并移除对应脚本/命令即可；不影响开发数据库或真实网关任务。保留历史报告用于比较。
