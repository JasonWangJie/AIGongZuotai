# 002 · Go 本地执行核心与 Provider 边界

日期：2026-11-13。阶段：第一阶段本地开发纵向链路。

## 目的

将开发方案中的 LLM 实时流、图片/视频异步任务落成可运行 Go 后端，给前端提供可刷新、可取消、可重连的真实本地 API，并建立显式 New API LLM 联调边界。

## 范围

标准库 net/http、固定 worker、有界队列/缓冲、内存资源、幂等与请求校验、SSE 回放、集中媒体轮询、静态 demo 产物、同源保护、前端构建文件服务、LLM live adapter、关键状态机和 HTTP 测试。真实媒体路径与持久化未实现。

## 实际文件

- `go.mod`：锁定 Go 1.26.5，无第三方依赖。
- `cmd/server/main.go`：回环监听、配置、HTTP 限制、停止/drain。
- `internal/studio/model.go`：Run/Task/Artifact 与输入/事件模型。
- `internal/studio/app.go`：内存仓库、幂等、有界 worker、事件环与调度。
- `internal/studio/http.go`：全部 HTTP/SSE API、安全输入边界、静态 demo 与 SPA 服务。
- `internal/studio/provider.go`：demo Chat/Media、MediaProvider 边界、OpenAI 兼容文本 adapter 与解析器。
- `internal/studio/app_test.go`、`internal/studio/provider_test.go`：状态机、HTTP、隔离、流解析及本地 upstream fixture。
- `docs/api/openapi.yaml`：当前已实现接口契约。
- `docs/wiki/backend.md`：运行参数、行为、限制与验证证据。
- `docs/changes/2026-11-13-002-go-core.md`：本台账。

## 接口与数据影响

新建 `/healthz`、`/api/v1/bootstrap`、runs/tasks 的创建/查询/列表/取消、运行 SSE 与工作区 SSE，以及 `/demo-assets/` 本地产物。创建要求 Idempotency-Key，同键异参 409；JSON 请求最多 64 KiB，prompt 最大 16,000 字节。资源在内存中，每类上限 512；服务重启清空。完整 schema 见 [OpenAPI](../api/openapi.yaml)。

APP_ADDR 默认 `127.0.0.1:8080` 且拒绝非回环监听；PROVIDER_MODE 默认 demo，live 必须显式提供网关 API 根、key 和模型。APP_WEB_DIR 默认 `apps/workbench/dist`。run.snapshot 的 SSE data 是完整 Run 对象，Last-Event-ID 优先 URL after。

## 验证结果

- `go test ./...`：通过，包含本地 httptest 的完整流与媒体任务链路。
- `go vet ./...`：通过。

- 未发起真实 New API 请求、未做生产压测或持久化容灾验收。

## 风险与限制

仅本地单进程 memory，无登录、多租户 ACL、支付/账本、事务 outbox、分布式调度、指标/追踪或持久化幂等。live 仅单条文本 prompt，不含历史、工具与文件；图片/视频 live 返回 501。demo 图片是固定 SVG，视频仅海报；progress 为模拟，不是模型推理数据。浏览器断线不取消生成，平台取消不证明上游停止计费。上游断流失败后保留部分输出，不自动重发。

## 回滚方式

停止 Go 进程即可停止演示与清空内存；若 live 已显式配置，先在网关侧确认运行状态与计费。撤销上述本轮新增后端/契约文件及对应文档链接，前端恢复为无 API 提示。没有数据库迁移或外部资源需要回滚；不要删除既有开发方案或用户文件。
