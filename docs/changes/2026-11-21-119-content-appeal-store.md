# 119 · 原输出审核决定的独立内容申诉

## 目的

V14-C2a 允许本人对其实际生成、已被隔离的文本或媒体输出申请独立审议。审议结论可以维持决定、记录独立意见，或将仍有冻结额度的案件列入财务待核实队列。账户限制、账户申诉属于后续 C2b，自动额度风控属于 C3。

## 范围

V14-C2a，已执行输出的原证据与独立审议。

## 实际文件

- `db/migrations/026_content_appeals.sql` 建立申请、原键、计划、不可改收据、财务工单关联、原资源实名审计与释放分录索引。025 及之前 SQL 保持原始内容。
- `internal/studio/content_appeal_store.go` 实现来源、身份、原键、容量与隐私投影；`content_appeal_action.go` 处理独立审议预演、密码确认、CAS 与回执；`content_appeal_store_test.go` 验证这些行为。
- 运营权限、HTTP 路由及财务关联由本批配套变更负责，工作台与后台联合验证分别登记。

## 接口与数据影响

申请绑定同一工作区和项目、实名受理审计中的用户、原 Run/Task、实际审核决定及版本。用于文本的证据包括持久化的执行身份，媒体需有原任务不可改的私有候选记录。已存在的 021 前文本可通过早于 021 迁移的输出审核记录、原隔离错误与实名受理审计佐证。没有业务资源的输入拒绝、取消、生成中断、跨项目资源以及其他人的申请均不会成为本人的可申诉输出。

申请保存原决定、策略、证据摘要、原资源版本和私有陈述。每项决定每人仅一份，申请原键绑定完整输入。正文与本人公开答复只在申请人、目标工作区的显式内容审核员详情中读取，列表展示有界状态摘要。工作区最多 1024 份、全局最多 100000 份申请。每页最多 50 份，游标绑定用户、角色、工作区、项目和筛选。每份申请仅保留一张未消费预演；已执行预演和收据保留。

审议需当前 `content_appeal_review` 授权，申请人不能预演或执行自己的申请。预演在数据库保存点实际执行并回滚；五分钟有效摘要绑定不可变决定、完整请求、原审核员、会话、凭据、grant、数据库身份和适用的原冻结版本。执行前重新验证密码、事务内复核上述约束与截止时间，审议、运营审计、消费计划及唯一收据同事务。审计不携带原陈述、回复、原提示词或私有原件。

`FINANCE_REFERRED` 需要原资源仍存在正数的 `REVIEW` 冻结。实际建单、财务密码预演与 CREDIT 释放分别受财务授权约束，审议本身不动余额。原审核决定、未公开文本、隔离媒体和任务保持原记录。本人可以按原申请查询最终公开答复与已核实的财务结果。

- `go test ./internal/studio -run '^TestContentAppeal' -count=1 -v` 首次有两项用例通过，包耗时 0.256 秒。覆盖申请长度、无效类型与版本、非法指令、私有证据的 JSON 隔离及财务投影。
- 集成人真实 PG 首轮 `TestPostgresContentAppealFinanceReceiptAndRelease` 4.66 秒，`TestPostgresContentAppealEvidenceOwnershipPrivacyAndSecondOpinion` 6.31 秒，`TestPostgresContentAppealFinancialPlanFencesStaleReserveAndSession` 3.56 秒，均通过。验证原申请人、同键异参、隐私清单、审核员回避与当前密码，及账务版本变化、数据库锁等待跨预演到期和撤销会话后的原子拒绝。首轮升级试具因旧媒体记录缺少调度所需的 `provider_mode` 报错；浏览器首轮未读到预期界面状态。该组整体未通过，记录在 `.runtime/v14c2a-first.log`。
- 集成人第二轮串行运行全部 8 个专项，用时 38.538 秒，均通过。原决定归属与独立意见用时 2.24 秒，过期预演与撤权用时 4.16 秒；财务真实收据与释放用时 3.38 秒，025 原决定升级用时 1.18 秒，浏览器从本人申诉追溯原财务收据用时 18.95 秒；离线工具拒绝旧 025、缺失 019 和未来 027 用时 8.49 秒。记录在 `.runtime/v14c2a-second.log`。

## 风险与限制

保留在旧库的来源必须能证明原申请人和实际输出决定。受理时未留实名审计的数据不能推定为当事人所有。文本隔离候选未持久保存，不能重建其正文。媒体不因提交申诉而自动复审、公开或下载。没有真实审核商验收，本地审核与 PG 试具不能证明实际语义准确率。

## 回滚方式

停机恢复升级前同一点的 025 数据库、私有目录、owner、需用的密钥及对象版本，配套使用旧版本程序。核对新申请、复核收据、工单和 CREDIT 分录后再切换。
