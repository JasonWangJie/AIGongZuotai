# 003：React 工作台与接口集成

日期：2026-11-13。实施状态：第一阶段本地工作台完成，生产放行条件未完成。

## 目的

将离线视觉蓝图落实为可运行的 React + TypeScript 工作台，真实连接 Go API，贯通对话流、异步媒体任务、取消、历史恢复与作品展示。默认演示 Provider 必须在界面明确标识，不能以浏览器定时器假 API 充当主链路。

## 范围

新增独立 Vite 前端子项目。实现对话、图像、视频、任务中心、作品素材与本地创意草稿，统一模型与比例参数、提示词模板、折叠检查器和移动导航。新增资源事件合并与幂等重试逻辑、7 项状态测试、模块 Wiki。原有离线蓝图和总体方案保持独立。

- `apps/workbench/src/App.tsx`、`components.tsx`、`styles.css`：工作台、原生表单、原创 SVG、可编辑草稿、响应式布局和减少动态效果支持。

## 接口与数据影响

前端只请求同源 `/api/v1`，Vite 将 `/api`、`/healthz`、`/demo-assets` 转发至 `127.0.0.1:8080`。读取 bootstrap 与历史；创建任务／运行时发送 UUID 幂等键；取消调用服务端取消接口。任务以工作区 SSE 推送并按版本合并；当前选中运行以 SSE 接收增量、快照与终态，40ms 批量刷新文本。

断线不自动重发 POST。受理不明操作保留请求体与原键供显式重试，刷新历史后仍保留提示。流序号缺口触发快照恢复。live 模式的媒体生成按钮禁用，直到二开异步契约落地。素材只允许同源受控路由；模型文字不作为原始 HTML 渲染。

客户端仅将文字草稿保存到 localStorage，键为 `xingtu-local-draft-v1`，最多 40 个节点。没有新增数据库表或存储网关密钥。演示模式的服务端内存记录重启会丢失；前端标识来自 bootstrap。

交付前浏览器联调修正：视频数量固定显示 1 且禁用增减，在纯请求构造函数中也强制 `count=1`；图片 1—4 张保持可调。描述从 8,000 改为最多 5,000 个 UTF-16 单元，并在提交函数校验；最坏中文编码 15,000 字节，符合 Go 16,000 字节限制。确认 `mediaUnavailable` 已在提交函数拦截，快捷键不能绕过按钮。同步补齐 `SUBMITTING`／`INGESTING` 的“提交中”／“结果入库中”状态文案。

同轮视觉修正：根据 1280×720 浏览器观察，新增 `min-width:861px` 且 `max-height:800px` 的短屏紧凑布局，收紧标题、输入区、模式提示和灵感区间距，输入框最小高度设为 70px；保持正文／按钮字号，不改变手机布局。目的是在短屏首屏展示原创 SVG 参考画面，具体浏览器复核由汇总负责人记录。

## 验证结果

- `npm --prefix apps/workbench run typecheck`：独立 TypeScript 严格类型检查通过。
- `npm --prefix apps/workbench run build`：TypeScript 与 Vite 生产构建通过。产物约 JS 265kB / gzip 84kB，CSS 34kB / gzip 8kB。
- `npm --prefix apps/workbench test`：1 个测试文件、7 项测试通过，覆盖版本去重、终态保护、Unicode 增量、缺口与快照恢复。
- 浏览器联调后的追加验证：新增图片四张切换视频一份、无效图片数量和 5,000 字符中文编码边界测试；2 个测试文件、10 项测试通过，独立 typecheck 与 build 均通过。JS 265.17kB / gzip 84.41kB；随后追加短屏 CSS 并再次构建。
- 初次构建因一条多余的空 CSS import 失败，已移除并重新构建通过。
- 初次依赖审计提示旧 Vitest 的 3 项开发依赖问题；已升级 Vitest 5.1.0，最终 `npm --prefix apps/workbench audit` 输出为 0 vulnerabilities。
- 未由前端作者进行前台浏览器操作；端到端浏览器与 API smoke 由汇总负责人另行记录。以上不等同于真机、容量或真实网关验收。

## 风险与限制

当前是单工作区、本地开发版，不具备生产鉴权、多租户、支付、协同或持久化可靠性。演示 Provider 交付预设结果，视频演示为 SVG 参考，不是真实视频。真实模式暂只有 LLM。

草稿支持新增、编辑和删除，没有拖拽、连线与工作流执行。对话暂按纯文本显示；历史与素材尚未分页／虚拟化；每个标签页独立订阅，未实现 leader 共享连接。受理不明请求只驻留当前页面内存，刷新后需历史对账。系统字体、响应式与 reduced-motion 已实现，但尚不能声称全部浏览器和移动实机通过验收。
