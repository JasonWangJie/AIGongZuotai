# V14-C3 · 付费生成额度风控

## 范围与依赖

C3 在持久身份、V12 报价冻结和 V14 运营权限的基础上，验证工作区有价生成的冻结上限与频率限制。涉及 H01、H03、H05、H06、H07、H08、H09。工作区所有者可以看到自己原报价的复核入口。独立授权的 risk_reviewer 可以处理指定工作区的申请。默认不启用规则。

## 新受理

运维人员停写后为工作区设置未结冻结额上限和整 UTC 分钟内新受理的有价生成数。规则修改追加新版本。实际受理先处理原幂等重放，再核对原报价、用户和账户限制。获得钱包锁后，以数据库时间检查报价有效性、已有冻结和窗口内已提交的预约。REVIEW 中未释放的额度继续占用。有价 Run、Task、会话请求和工作流子步骤使用同一条冻结路径。被拒绝时不消费报价，不创建资源或新冻结。

## 误伤复核

本人针对仍有效且实际触发限制的原报价申请复核。申请绑定原账户、项目、报价、输入摘要、金额、价格与策略版本。运营人员独立预演、核验当前密码并明确批准或拒绝。本人的单次批准只适用于这张有效报价。手动提交原请求后，豁免核销与业务、权益冻结及正式预约同事务。过期、换策略、余额不足、工作区受限或内容审核拒绝均需按相应规则处理。已经受理的工作继续依原规则，不因额度复核再生成。

## 验收

验证双请求争用同一钱包和单次许可、窗口切换、未知执行与冻结占用、旧报价归属、原幂等、策略修改与过期、跨身份/工作区访问。用本地真实浏览器走完付费图片被拒、本人申请、独立运营批准、本人明确重提、私有图片交付与原金额结算。联备后核对政策、申请、决定、唯一预约和资产。[联合验证](../changes/2026-11-22-130-credit-risk-integration.md)
