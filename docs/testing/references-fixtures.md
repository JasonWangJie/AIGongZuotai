# Reference upload fixtures

`source.png` and `source.webp` are original synthetic geometric landscape fixtures created for this repository. They contain no personal data and are not AI generation results. Both are 960×640; the WebP file is lossless. Used for full decode, MIME validation, thumbnail, upload/edit integration and local browser QA. The upstream test server returns a separate synthetic PNG response; fixture success does not establish real supplier image editing quality.

样本原件继续位于 [`internal/studio/testdata/references/`](../../internal/studio/testdata/references/)，测试读取路径未变。
