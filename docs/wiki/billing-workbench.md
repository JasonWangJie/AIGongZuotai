# 工作区权益与报价交互

侧栏“工作区权益”覆盖当前工作区全部项目，展示可用、冻结、累计结算和累计冲正。待核实金额已包含在冻结中；累计消费是毛额，冲正单列，不重复扣减。demo明确显示“本地演示额度（非付款余额）”，没有充值按钮。

流水和冻结单支持项目、类型/状态筛选，按时间倒序；每次20条、本页最多200条，达到上限提示缩小筛选范围。钱包不是项目余额，切项目仍显示同一工作区额度。读取错误、空数据、加载和限流冷却分别显示，过时请求结果不跨账户/项目/筛选覆盖。

聊天先新建或选择空会话，再输入内容获取报价；空会话不执行模型、不冻结。图像/视频按当前模型、完整规格、数量、操作及参考图顺序报价。报价展示最大冻结、有效期、单价和结算依据，只有“确认额度并提交”才执行。修改原输入、模型、身份或分支会清除旧报价；已经发出的有效报价保留原价格承诺。

网络受理不明时保留原body、操作键和quote_id，必须走“原请求重试”，不能因报价过期换键重发。输入及未知请求只在本页内存，刷新或关闭前需要核对/保存。聊天继续是新请求，需要再次确认报价。

任务/聊天卡片同时展示生成状态和结算状态；生成完成但usage缺失时仍可为待核实，不把取消、失败或没有可见输出视为免费。金额用BigInt整数格式化，保持六位精度，不按浮点或文字长度估费。
