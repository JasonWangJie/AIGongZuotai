# 038　固定分镜、视频任务与局部重做

## 决策与范围

在已确认的项目分镜版本上选一镜，由服务端根据该版本的角色、场景和动作生成提示。用户查看完整视频规格、提示及适用的 CREDIT 报价，显式提交后由普通媒体通道执行。任务使用的原模型、原请求、权益、审核、提交不明与恢复规则继续适用。

## 选择理由

固定版本与稳定镜头 ID 可以在项目内容继续编辑后重新核对来源。直接发送当前页面中可更改的镜头文本会丢失这一依据。将产物自动写回剪辑稿会覆盖用户在生成期间所做的选择。生成受理与版本替换因此各有自己的显式操作、原键和收据。

## 实施与验收

V20-B 本机链路已通过 PostgreSQL 和 Chromium 验收。两份私有剪辑导出各 54 帧，首镜画面和 440 Hz 音轨一致，第二镜由红片改为蓝片，音轨变为 880 Hz。停写联备后原键可读，私有原件逐份相同。供应商对原视频编辑和延长的请求格式、授权素材与真实效果继续单独验收。[225 集成记录](../../changes/2026-11-22-225-panel-video-integration.md)。
