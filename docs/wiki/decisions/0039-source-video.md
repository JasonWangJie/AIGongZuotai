# 039　私有原视频编辑与延长

## 决策

用户选择项目资产及其元数据修订。服务端同时核对来源任务、已公开 MP4、素材状态、审核结果及相应交付收据，最终受理事务再锁定并核对同一来源。新任务在 039 表登记原作者、原视频任务、产物、修订与内容 SHA-256。既有任务沿用原记录。

## 选择理由

供应商的编辑与延长接口各有独立路径。原任务 ID 无法表示视频文件；浏览器提供外部地址也无法证明素材归属。选用模型明确接收的 Data URI，由服务端从私有存储读取原件并写入私有请求文件。这样能保留当时的准确字节、参数、审核证据与幂等键，同时沿用普通报价、任务与资产交付链路。

## 配置与边界

在视频模型的 `capabilities.source_video` 中分别用 `data_uri_edit_presets`、`data_uri_extend_presets` 引用本模型的完整规格 ID。可用延长方向写入 `extension_directions`。省略配置时对应模型不开启这些操作。采用 CREDIT 的环境分别配置 `video_edit`、`video_extend` 的单产物价格。受理回应丢失时由原账户按原项目、原键读取收据。

例如，若已开通的模型明确支持编辑和向后延长 5 秒、720p 的横向视频，可在其现有 `capabilities` 内加入以下字段。`landscape-five` 是仓库示例中已有的规格 ID。实际配置请引用该模型已核实的规格，并保留现有目录的其他模型和能力。[模型目录示例](../../../config/models.example.json)

```json
{
  "source_video": {
    "data_uri_edit_presets": ["landscape-five"],
    "data_uri_extend_presets": ["landscape-five"],
    "extension_directions": ["forward"]
  }
}
```

在服务器应用目录后重启，再从「视频工作室」检查模型的编辑、延长、方向及规格选项。选择已登记的项目原片后可先查看报价，点击确认才会受理生成。服务端保管供应商凭据。[价格目录结构示例](../../../config/prices.demo.example.json) · [报价与生成实测](../../changes/2026-11-23-239-source-video-browser.md)

来源限已交付且可用的项目私有 MP4，大小上限 32 MiB。受理前检查容器结构、视频轨样本描述、尺寸、媒体数据及本地引用，再核对读出的完整字节。网关限制按含 Base64 和 JSON 的完整请求体计量，上限 64 MiB。

## 实施与恢复

039 增量和离线工具使用同一版本。停写后联备数据库、资产和参考目录及其 owner、交付和其他已启用的密钥、相应对象版本。回退时在独立位置恢复匹配的 038 备份及制品，保留 039 期间的新任务与账务收据以便核对。真实供应商的授权、实际模型支持和输出效果另行验收。[业务台账](../../changes/2026-11-22-235-video-source-admission.md)

工作室在素材库更新时单独核对所选资产。仍可读且修订相同则保留方向和原报价，复核失败可以重新核对。已变更或回收的资产须重新选择。响应正文截断可在当前页面点击「查询原任务收据」。真实 Chromium 也测得在无响应头时底层重送相同 POST，服务端复用原任务和原冻结，只产生一次上游执行。[浏览器两档验收](../../changes/2026-11-23-239-source-video-browser.md)

本机版本化对象服务验收在同一键写入另一版本后执行编辑、延长并停写恢复，两次受理与恢复读取均使用登记的原版本。[联备与对象版本](../../changes/2026-11-23-238-source-video-integration-restore.md)

工作台组件测试用受控时钟触发项目通知后的素材复核，分别覆盖原片修订变化、暂时读取失败、回收或不可读，以及提交回应丢失后五次原键回执查询。实际浏览器断线和底层重送由 Chromium 专项验证。[040 累计回归](../../changes/2026-11-23-251-format-040-regression.md)
