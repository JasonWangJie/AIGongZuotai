# ADR 0008：账户恢复与加密安全邮件

日期：2026-11-13。状态：v0.10本地实现；V11实际邮件渠道按用户安排后续配置。批次H01/H06/H07/H08/H09，见[039—042台账](../../changes/README.md)。

## 背景

付费运营需要用户能验证邮箱、恢复账户和撤销登录。邮件服务器接受数据与平台事务无法原子提交，密码变更也可能与旧密码验证并发。不能因为页面报告成功就推断邮件送达，不能让已经失效的密码验证结果重新签发会话。

## 决策

账户以单调凭据版本隔离新旧密码、会话和一次性令牌。bcrypt在有界槽位执行，不占数据库锁；随后锁用户行并重新核对原密码散列和版本。改密/重置、版本增长、会话撤销、旧令牌失效与账户私有安全事件在同一事务提交。旧会话由011回填公开ID及版本1，保持升级兼容。

随机32字节令牌在身份表只存SHA256摘要，按用途和到期时间单次消费；验证24小时、找回30分钟。邮箱请求、摘要、加密发件项及成功安全事件同事务；邮件worker提交后才使用TLS SMTP，网络I/O不持DB锁。公开找回已知/未知邮箱返回同一202正文，SMTP异步；不承诺严格恒定响应时长或全站无枚举渠道。

邮件载荷包含可使用的token，故必须用独立32字节AES-GCM密钥加密，AAD绑定记录ID/用途/到期。发件队列只存密文，不保存明文收件人/链接/正文。明确未接收可以有界退避，DATA接收确认丢失或重启遗留SENDING转为SUBMIT_UNKNOWN，停止自动重发。SENT表示SMTP接受，不等于进入收件箱。

链接仅使用服务端可信origin和fragment，前端启动即移除地址栏token，用户显式确认才提交。密码/令牌不进本地存储、草稿或生成任务恢复仓。敏感请求结果不明只引导核对/重新登录/申请新链接，不能套用AI生成的幂等重放。身份切换后旧响应不得更新新账户页面。

## 替代项与后果

同步发送使SMTP延迟进入认证接口，且事务回滚后可能留下有效性不明的邮件，因此不采用。明文Outbox方便运维但暴露账户恢复凭据，因此不采用。SMTP没有可依赖的Message-ID去重承诺，不采用无条件重投；代价是未知投递需用户另申请新链接。

独立队列密钥必须安全联备，当前不提供多密钥滚动轮换。停用邮件停止worker与清理；旧邮件仍可能延迟到达，但密码版本已使旧token无效。011回退必须使用匹配的数据库和私有文件备份，保留升级后原库，禁止删迁移登记。当前限流仍是有界进程内计数，无MFA、失败登录风险平台或多实例身份集群。
