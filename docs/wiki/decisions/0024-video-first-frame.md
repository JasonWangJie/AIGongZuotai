# 0024 · 将选定原图作为视频首帧

## 决策

保留三步选图模板。新的四步模板有两个视频输入：已公开的脚本文本和人工确认的同项目图片。工作流进入等待生成视频后，用户可查看首帧、模型、时长和完整规格，再单独授权视频生成。视频模型须通过私有目录声明 `video_first_frame_supported`；权益模式另需对应规格的 `first_frame` 费率。[工作流设计](../../planning/v19-contract.md)

## 渠道与输入

原网关公开文档列出视频异步生成的 multipart 文件字段 `input_reference`。服务端核验项目、工作流、审核结果、原任务与产物、内容版本、原件大小和摘要，随后把实际图片写入冻结的 multipart 正文。发送身份、完整正文与子任务随原请求保存；查询和导入沿用原 handle 与现有私有交付。浏览器只能引用已确认的项目资产。[网关公开说明](https://api.aiimg.lol/async-image-api-docs) · [所核对的协议版本](../../../internal/studio/testdata/media/video-first-frame-source.json)

## 方案取舍与后果

只把图片 ID 写入流程记录不能让模型看到图片。直接发送下载链接会把私有资产授权带到外部；换用另一供应商还会引入新的凭据和查询协议。传输经核验的原件可以在受理前发现选图变化，并在本地供应端逐字节比对。模型实际开放的输入、费用和效果仍须配置相应账户并另行验证。

## 格式与回退

024 在数据库增加视频阶段、同项目子任务外键和已批准的交付资产。已有 023 模板、选择与收据保持原状态，迁移不替历史流程追加视频。升级前联备 PG、两处私有目录、owner、有效密钥和对象版本。需回退时恢复升级前成套副本，再运行对应版本。[迁移目录](../../../db/migrations/024_workflow_video.sql)
