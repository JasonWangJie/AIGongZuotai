# ADR 0009：平台权益、可信计量与不可变账本

状态：V12于2026-11-14完成本地权益账本验收，证据见046和TODO；真实支付与供应商成本核对仍属后续批次。

平台与New API之间有实时LLM和异步媒体两种契约。异步文档没有明确quota/cost单位，LLM流可能缺usage或在执行后中断。因此平台权益与供应商成本、实际支付分开建模。

采用六位CREDIT整数；API使用十进制字符串；报价持久10分钟并冻结版本。受理与最大额度冻结同事务，已执行的未知成本保持REVIEW。聊天只接受完整有效usage；媒体按已导入注册的交付数量计价。这样用户确认的是明确平台价，不能借估算或未定义quota猜测最终消费。使用小数浮点、仅在完成后扣款、失败一律退回、浏览器直接计价均不采用。

不可变journal/posting记录双分录，数据库延迟约束检查平衡并禁止更新删除。钱包与冻结单为可核对投影，所有转移与业务终态/审计/Outbox同事务。精确原键重放优先于新请求校验；报价消费一次，禁止换键复用。取消或旧worker不具备额外扣减权。

初期管理入口使用停机CLI：预演默认回滚、精确计划摘要、幂等操作键、原因/证据、只允许全额一次冲正及REVIEW核实。浏览器不暴露赠送、任意改余额或支付退款能力。代价是人工处理需要短暂停机；在线权限审批/财务控制台属于后续运营模块，不能把当前CLI当成完整财务系统。

保留默认disabled以兼容旧资源，旧记录无冻结则不追扣；开启必须PG+鉴权+明确价格文件。demo价格只能对应demo，测试执行环境隔离邮件和权益配置。012前联备、格式栅栏和不可变历史是恢复边界。
