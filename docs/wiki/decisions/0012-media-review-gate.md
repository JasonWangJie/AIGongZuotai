# ADR 0012：媒体候选与正式交付分离

状态：V14-B2本地实现，联合验收见[058](../../changes/2026-11-14-058-media-review-integration.md)；真实审核商尚未选型。

## 原因

媒体网关异步返回后，原链路直接导入私有存储、注册资产并结算。只隐藏前端不能阻止旧下载入口，也无法处理审核期间取消、租约变更或提交确认丢失。图片编辑还需要检查实际有序参考原件。

## 决策

独立media-v1策略与文本策略分开冻结；016保存不可变私有候选、批准摘要及决策历史。审核读取完整原件字节，校验大小与SHA256，在全局锁和数据库事务外执行。S3私有版本对象先验证再审核，禁止以URL、缩略图或供应商file_id代替实际内容。

原handle查到结果后，先由有效租约提交PENDING候选，再锁外审核整组。只有全组ALLOW且供应商SUCCEEDED/PARTIAL，才能同事务写终决策、公开产物、资产目录、权益与Outbox；提交确认后才替换缓存。任一BLOCK/REVIEW则整组隔离，已执行额度保持REVIEW。新参考上传只在原件通过后同事务登记参考、目录、幂等与审计。

已登记候选的取消、宕机和租约失效不得自动放行、重审或重新生成；恢复保持REVIEW。无候选且保留原handle的待核实任务，可在服务端明确允许时继续原Query。旧幂等优先；关闭审核不批准已隔离内容。财务处置不修改内容决定。

## 替代项

- 导入后先公开再检查：内容已交付，无法撤回，因此不用。
- 单张通过立即开放：产生部分泄漏与结算歧义；本批按整组通过交付。
- 只审核供应商URL或视频首帧：不能证明读取完整原件，也不能覆盖后续视频内容，因此不用。
- 将候选放数据库Base64：加重事务与备份；继续保存私有文件身份，文件与数据库联备。
- 未通过就自动释放额度：上游已执行，不能据此推定免费。

## 后果与边界

交付延迟包括下载和审核，候选持续占用私有存储配额。停机维护必须保留所有已登记候选，不能凭供应商终态删除；016与私有文件/队列密钥联备，旧写者精确栅栏。默认关闭，启用需要PG、账户和文本审核；fixture仅验证已登记字节，HTTP模拟器不代表真实语义准确率。人工申诉/复核、保留期限、生产渠道与容量另行验收，当前仍为单控制写者。
