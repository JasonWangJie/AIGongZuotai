# ADR 0011：文本全文审核后交付

状态：V14-B1本地实施与验收完成（2026-11-14）；实际证据见054，真实审核供应商尚未选型。

## 原因

原工作台的流片段立即写入Run.Output、检查点和SSE；事后遮盖前端不能撤回已交付内容，旧分支及上下文也可能继续引用。需要把候选文本与已交付文本分开，同时保留原幂等、用量与事务结算。

## 决策

默认关闭。开启后先对完整实际messages输入审核，锁外调用；重入重新核验输入摘要及CAS，冻结策略同受理事务保存。模型仍在服务端流式消费并取得真实usage，但未审输出只在有界私有内存缓冲。整段允许且COMPLETED同事务成功才将正文写入公开Run并发布快照。

输出阻断/未知及取消/崩溃保持隔离；已执行费用仍待核实。规则引擎仅demo验收，真实HTTP渠道另验；不假装关键词表等同语义审核。旧资源无审核标记保持历史行为，新媒体请求在本轮开启时拒绝直到B2实现。

## 替代项

- 先stream再审核：已经向客户端交付，不能实现阻断，因此不采用。
- 分片逐段审核：可能遗漏跨段语义，并需明确窗口/撤回协议，留待独立设计。
- 所有文本持久化待人工审核：引入新的敏感候选保留、权限及删除生命周期，本轮不扩展；候选仅内存，崩溃明确丢弃。
- 将未公开结果自动免费：上游可能已经执行，不能破坏既有REVIEW与人工核账政策。

## 后果与实施边界

审核开启时首字交付推迟到全文完成及审核通过，界面明确提示；关闭时保留原实时流行为。没有人工重审/放行、追溯屏蔽旧资产或多模态审核，也不宣称生产语义准确率。015格式栅栏保存冻结策略与审核历史，升级联备；未知结果不能换键重新生成。
