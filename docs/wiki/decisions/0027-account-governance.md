# 0027 · 按目标账户授权限制与复核

工作区的 moderator 可以处理所在工作区的内容申诉。账户限制会同时影响本人在工作台上的普通访问，因此运营人员需要对指定目标账户单独取得授权。停写后使用 `cmd/operations` 的 `-user` 指定操作人、`-target-user` 指定目标。预演和提交复用同一稳定操作键，提交时提供预演的精确摘要。浏览器只能列出该操作人当前获授的目标。

## 会话与已有工作

限制和解除各自创建一笔正式收据，同一事务撤销目标的现有会话。限制期间，本人再次登录可以看到账户限制原因、当前轮次、个人申诉历史与账户安全入口。原会话在解除后仍然失效。重新登录后可访问原项目和已保存草稿。已提交的生成、原审核决定、隔离资产和已冻结额度继续使用各自的生命周期。

普通请求先核验会话。新报价和新生成在最终受理事务再次核验原用户与会话，覆盖锁外审核期间发生账户限制的情况。已接收的短读取可能完成。进行中的事件流定期检查会话，状态变化与已开始返回的字节存在检测窗口。

## 申诉与答复

本人每轮可申请一次，私有说明仅在本人和该目标获授权审议人的详情中读取。运营人员预演、查看影响并用自己的当前密码确认。维持决定只答复该次申诉。解除针对指定限制轮次，计划绑定申请集合、账户与授权版本。如结果未知，申请人按原键读回，运营人员按原计划读回。解除也会关闭当时尚开放的该轮申请。
