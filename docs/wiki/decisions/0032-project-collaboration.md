# 032 · 定向邀请与共享项目草稿

## 邀请与接受

已注册用户在侧栏「项目协作」查看自己的账户 ID。项目所有者输入目标 ID，核对目标关系与预期版本，授予只读或编辑角色后发出站内邀请。收件人从自己的协作收件箱核对项目、邀请人和角色，再显式接受。邀请有效期为 72 小时，按数据库时钟判断。过期、撤回或撤权后的再次邀请产生新轮次。

打开「共享项目」会进入所选项目的节点草稿。个人工作区和原活动项目保持各自身份。成员可以在当前权限内读取节点、历史版本与本人的保存回执。编辑角色可以保存修订，只读角色可以查看。所有者可撤回待接受的邀请、降权或撤权；重新进入共享项目时实时核验。

## 成员权怎样生效

会话始终绑定本人的原工作区。共享草稿有专用的项目路径。服务端在同一数据库事务重新核对账号、会话、目标项目和当前关系，取得授权后才访问该项目的节点草稿。共享入口不切换宿主身份。宿主的其他项目、媒体、生成、钱包、运营权限和事件订阅仍沿用各自原有的身份检查。

直接切换会话工作区会扩大按工作区查询的数据范围。另建一份“协作草稿”副本会产生两套正文和修订号。因此所有者与成员共用 003 的同一份草稿、修订、审计和事务 Outbox，仅成员的操作键另外与操作者绑定。原所有者的历史操作键继续有效。

## 冲突与原操作回查

两人从同一修订保存时，只能有一方成功。遇到冲突后，当前编辑者可以先核对服务器的新修订，再决定怎样处理页面上的输入。共享编辑不会自动覆盖迟到内容。连接中断后保留原键，只读查询原收据。草稿收据要求当前读权，降为只读后可以查看本人以前的已提交保存；撤权后即拒绝。

成员授权操作的历史收据记录当时结果。重读接受回执不会重授已撤销角色。所有授权变更和草稿取写共享项目行的锁顺序，等待中的旧写操作在获得锁后复核当前状态。

## 交付范围与恢复

本批提供站内定向邀请、项目草稿角色和乐观并发编辑。负责人在当前项目查看成员。历史关系可用精确账户 ID 查询以核对重邀版本。未保存冲突正文只在当前页面。实时光标、任意资源共享和实际邮件收件各有独立接口或验收条件。
