# 029 · 演示文稿版本与可编辑导出

## 产品范围

一个项目可以保存多份演示文稿。从文字材料整理大纲后，可以调整页面顺序、主题、标题、正文、讲者备注，并为页面选用当前项目内可读的图片。保存所得的每个版本可独立查看和导出。

## 为什么保存页数据

只存整页截图会丢失文字编辑和讲者备注；只依赖当前草稿会使同一个导出链接随编辑而变化。029 保存每一版有序页面和独立来源身份。导出使用已保存的指定版本，将文字写入原生 PowerPoint 形状，图片通过本平台的项目鉴权接口读取并嵌入文件。文稿自身无需保存网关地址、图片 Base64 或公开分享链接。

## 权限与故障恢复

打开和导出时重新校验当前账户、项目和图片。将源图移入回收站后，旧文稿文字仍可查看，整份带该图的导出须等待来源恢复可读。不同项目不能共用图片下载链接。若保存成功的响应丢失，可以查询原操作收据；同一文稿从过时版本修改需要显式解决冲突。

## 格式与验收

029 是追加迁移，保留原项目、草稿与工作流。备份包含数据库、私有目录及对应对象版本，已启用的独立密钥需要同时恢复。离线维护要求完整连续的 001—029。浏览器实际下载、独立编辑及渲染证据记录在[版本联合验收](../../changes/2026-11-22-138-presentation-integration.md)。队伍成员邀请依赖后续账户渠道，漫画分镜使用独立流程和验收条件。
