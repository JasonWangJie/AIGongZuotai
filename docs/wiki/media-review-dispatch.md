# 首次媒体审核持久分派

V16-A3.2 将首次输出审核从 query/delivery 移至独立 review 通道。新候选以可验证的 READY 标记排队，STARTED 确认提交后才检查真实私有字节并调用审核；旧候选和已经启动过的审核不自动重审。实现与实际验证见 [076](../changes/2026-11-14-076-media-review-dispatch.md)，联合状态以根079及任务源为准，当前仍在验收。

## 首次交接与旧记录

019 新增私有 `studio_media_review_dispatch`。它只存作用域、任务身份、完整候选摘要、冻结策略摘要、原 `SUCCEEDED/PARTIAL` 结果状态、派发状态/版本及一次 attempt 时间，不存来源 URL、提示词、文件正文或密钥。

| 状态 | 执行与恢复 |
| --- | --- |
| READY，版本1 | 与首次候选在原有效 lease 事务内新增；确认提交后结束 query/delivery 步骤。重启可执行尚未开始的首次审核。 |
| STARTED，版本2 | review worker 的当前 lease 提交一次 attempt 后才外发；重领、宕机或提交确认不明只能转 REVIEW。 |
| FINISHED | 与最终决定同事务完成；不能再次启动或改写 attempt。READY直接隔离为版本2，STARTED结束为版本3。 |
| 无019记录的旧候选 | 沿用B2旧隔离语义，绝不补造READY。 |

所有新 B2 输出，包括本地 demo 和非 phased 适配器，都使用交接。没有启用媒体审核的任务沿用原交付路径。019 不回填018已有候选，也不修改001—018迁移字节。018已有收据但尚未生成候选的任务，可以在首次候选创建时形成新 READY。

原结果状态单独冻结，因此审核后的 PARTIAL 不会因中间任务状态为 MODERATING 而变成 SUCCEEDED。公开 Task 和审核摘要仍使用已有 MODERATING/PENDING，没有下发新的重审令牌或浏览器重发操作。

## 容量、连接与私有读取

`MEDIA_REVIEW_WORKERS` / `MediaScheduling.ReviewWorkers` 默认2，显式范围1—2；第四通道有独立有界执行预算和 PG 辅助连接。领取顺序为 review 预算、同一审核引擎许可、连接、当前 lease。许可忙时留在 READY，不写 STARTED、不外发，不把暂时繁忙改成永久 REVIEW。

引擎的两个许可由参考输入和输出共享；输出不会另建池扩大总并发。整组依原候选顺序检查，持有同一许可；预算保持到保存和清理真正返回。取消会及时撤销活动审核 context，但不提前释放仍在退出的调用容量。慢审核不再占用 query/delivery 工作线程。

每件先读取同一私有原件描述符并核对真实编码、大小与哈希，完整 `AssetInfo` 必须与冻结候选相同，包括 Delivery 标记、创建时间、缩略图身份及对象位置/版本；缩略图也必须通过本地完整字节验证或 S3 私有完整 GET 校验。原件哈希相同但 manifest 被改、缩略图缺失或篡改都不能调用审核后放行。

审核不需要生成供应商或签名下载 URL。已有018交付记录仍必须提供原独立密钥；只有还需要 Import 的 READY 交付要求 phased 生成适配器。已经有019 READY/STARTED及全部逐件收据的记录可直接用私有存储审核；不允许 Query/POST 来补审核。

每件审核周期最多使用原私有读取2分钟与审核60秒的预算；整批总期限按件数计算，最多 `4 × 3分钟 + 30秒`。所有等待有界，四件候选不会被通用媒体步骤的2分钟总期限错误截断。S3临时副本、HTTP、读取描述符及许可仍按取消和关闭规则清理。

## 提交、取消及费用

- STARTED实际回滚：数据库仍为READY，零审核外发，可再次首次领取。
- STARTED已提交但ACK丢失：调用方不外发，恢复按已启动事实隔离，不能猜测“其实没发”并重审。
- ALLOWED已返回但Outbox满：只重试原决定保存，保留review及共享许可，不能重读再审。
- 最终决定、FINISHED、018 COMPLETE/PARKED、公开资产、权益、Outbox同事务；未确认不替换缓存或发布事件。
- READY/STARTED继续占用未完成资源和冻结权益；REVIEW不自动收费或释放。财务处置不改变内容决定。
- 取消、失租和运营修改沿用owner/epoch/generation及任务版本条件，迟到ALLOWED不能复活任务。旧派发版本、attempt或时间点改变均拒绝；PG时间的时区表示不同但代表同一瞬间不算身份变化。

当前审核引擎关闭或与冻结策略不兼容时，READY明确隔离；不会等待一个永远不存在的许可，也不会用新策略批准旧内容。策略版本更新仍按完整冻结策略执行，不按当前规则重新猜测。
