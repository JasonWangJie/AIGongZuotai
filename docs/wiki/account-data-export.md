# 本人资料下载

登录后进入「账户安全」，在本人资料下载区域选择范围。受限账户从自己的账户安全入口进入。选择范围后，输入当前密码并确认下载。文件保存到浏览器所选位置。

| 选择 | 文件内容 |
| --- | --- |
| 账户资料 | 本人账户编号、显示名称、邮箱、注册时间和邮箱验证时间 |
| 安全事件 | 本人的安全事件编号、动作和发生时间 |
| 账户申诉 | 本人提交的账户申诉、说明、公开答复、处理状态和时间 |

安全事件和申诉按创建时间及编号倒序分页。每页最多 100 条，完整附件最多 512 KiB。还有记录时可选下一页，重新输入密码确认。首页确定创建截止时间，文件同时标出本页实际读取时间；后续更新的答复和较晚提交的旧记录可能反映在后续读取中。密码变更后从首页重新开始。关闭页面会丢弃当前分页位置。

服务端在生成附件前核验当前密码、账户和会话；个人数据接口只读。浏览器核对账号、分区、内容长度、文件字段和 SHA-256 后才提供下载。下载的 JSON 可包含个人联系方式和本人申诉正文，请按个人资料保管。内部运营材料、会话凭据、工作区资源和其他用户的信息均在导出范围之外。
